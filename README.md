# Reserved Click MVP

Chrome/Edge 개발자 모드에서 압축 해제 폴더로 로드해 사용하는 예약 클릭 확장 프로그램입니다.

## 사용 방법

1. Chrome 또는 Edge에서 확장 프로그램 관리 화면을 엽니다.
2. 개발자 모드를 켭니다.
3. `압축 해제된 확장 프로그램 로드`를 선택하고 `dist` 폴더를 지정합니다.
4. 클릭 대상 페이지를 연 뒤 확장 프로그램 팝업에서 값을 입력합니다.

입력값:

- 현재 시각: 활성 탭의 서버 `Date` 헤더를 읽을 수 있으면 서버 기준 한국 시간으로 표시, 읽을 수 없으면 기기 기준 한국 시간으로 표시
- 날짜: 캘린더 UI에서 선택
- 시간: 시간 선택 UI에서 선택
- 버튼 선택: 현재 탭에서 후보 버튼을 직접 클릭해 저장

## 동작 범위

대상 후보 셀렉터는 다음과 같습니다.

```css
button, a, input[type='button'], input[type='submit'], [role='button']
```

확장 프로그램은 보이는 요소만 후보로 인정하고, 지정 시각에 해당 요소를 `scrollIntoView()` 한 뒤 `click()`을 실행합니다. 성공/실패는 서버 접수 여부가 아니라 확장 프로그램이 대상 요소를 찾아 `click()`을 실행했는지를 기준으로 기록합니다.

브라우저에서 선택한 버튼 정보는 저장되어 예약 시 다시 찾습니다. 페이지 구조가 크게 바뀌면 선택한 요소를 찾지 못할 수 있습니다.

현재 시각은 팝업을 연 활성 탭 URL에 요청해 받은 HTTP `Date` 헤더를 기준으로 추정하고 한국 시간으로 표기합니다. 해당 페이지가 서버 시각을 제공하지 않거나 요청이 제한되거나 기기 시간과 10분 이상 어긋나면 기기 시각을 한국 시간으로 표시하고 예약도 같은 기준으로 계산합니다.

## 상태

- `scheduled`: 예약됨
- `clicked`: 버튼을 찾아 클릭 실행 완료
- `failed`: 시간이 지났거나 버튼을 못 찾음
- `cancelled`: 사용자가 예약 취소

팝업을 닫았다 다시 열어도 마지막 상태는 `chrome.storage.local`에 저장되어 표시됩니다.

## 제한

Manifest V3 권한은 `activeTab`, `scripting`, `storage`만 사용합니다. 별도 백그라운드 알람을 쓰지 않으므로 탭 새로고침, 브라우저 종료, PC 절전 상태에서는 예약 실행을 보장하지 않습니다.
